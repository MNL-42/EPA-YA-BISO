# EPA-YA-BISO

Prototype jouable de découverte urbaine inspiré de Kinshasa (RDC).

## Lancer
Ouvrir `index.html` dans un navigateur moderne (Android ou ordinateur). Aucun serveur ni bibliothèque externe n'est requis.

## Commandes
- Mobile : flèches à l'écran.
- Clavier : flèches ou WASD.
- Approche-toi d'un taxi jaune et utilise le bouton d'action pour monter ou descendre.

## État
Démo 01 : déplacement libre, caméra qui suit le joueur, quartiers stylisés (Gombe, Matonge, Limete), routes, parcelles, marchés, taxis et mini-carte.

Ce prototype est une première base 2D jouable pour valider l'ambiance et les contrôles. Ce n'est pas encore un binaire PSP/PPSSPP. La conversion PSP nécessitera une version native compilée avec la toolchain PSP.
